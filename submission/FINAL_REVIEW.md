# Финальная проверка ІЗ · 23 октября 2026

Текущий движок: **2.0.1-track1-evidence**. Сайт — браузерный статический MVP; проверка не является гарантией отсутствия ошибок или готовности к самостоятельным юридическим решениям.

## Исправления

| Проблема | После исправления |
|---|---|
| Исправление источника из одних пробелов ломало резервную копию | Пустой текст отклоняется, исходный материал сохраняется |
| При отказе хранилища показывался успех | Изменение откатывается, форма и введённый текст остаются открытыми, ошибка видна |
| Черновик дополнения восстанавливался без родительского дела и становился недоступен | Копия включает только нужные исходные дела; ключи корректно переназначаются при импорте |
| «оцен» внутри «процентов» принималось за оценку жюри | В соответствующем правиле добавлена граница слова; финансовая комиссия не создаёт ложное противоречие в контрольном OCR-примере |
| Копии документов ссылались на отсутствующую папку с текущим отчётом | Ссылки исправлены, актуальный патч отделён от исторических результатов |

## Проверено программно

- **528/528** проверок контрактов и регрессий в 17 наборах; **340** исторических прогнозов воспроизведены без расхождений.
- Все проверки запускаются через `node scripts/verify.mjs` в собственной временной копии. Исходные исторические отчёты не перезаписываются.
- Первоначальный прогон после патча выявил устаревшую ссылку проверочного скрипта на dev-отчёт 2.0. Она заменена ссылкой на текущий 2.0.1 без удаления проверок. Неудачный прогон сохранён в `evaluation/final-verification-first.json`, успешный — в `evaluation/final-verification.json`.
- Восемь уже раскрытых AI-синтетических наборов пересчитаны относительно frozen2.0: изменения прогнозов отсутствуют; ошибки точных цитат 0. Новый независимый тест не проводился.
- Стандартные сигнатуры секретов проверены в исходном дереве и исторических текстовых объектах. Подтверждённых секретов не найдено. Это не полный pentest или аудит всех зависимостей.
- В тестовом HTML-экспорте опасный текст экранируется, `javascript:` и SVG data URL отбрасываются.

## Проверено в браузере

На отдельных локальных origin, без изменения пользовательских дел публичного сайта:

1. Создание дела из собственного синтетического текста → найденные признаки и точные цитаты.
2. Пустое исправление отклоняется в открытой форме; валидное исправление сохраняется и меняет расчёт.
3. Реально скачанные JSON и HTML; экспорт JSON содержит текущий и первый исходный текст.
4. Черновик дополнения скачан через интерфейс и импортирован в чистую среду. Исходное дело и точный текст с пробелами/переносами доступны в новой форме.
5. Загрузка контрольного PNG через настоящий file chooser → локальный OCR → исходное изображение рядом с текстом → экспорт. Распознанный текст совпал с прежним контрольным захватом; это одна проба, не оценка OCR реального потока.
6. Адаптивные главная, форма, дело и сеть; предыдущие проверки ширин 320/390/768/1024/1280px и lazy-загрузки отчёта сохранены отдельно. После текущего патча проверены мобильный экран и вид ноутбука.
7. При обычном прохождении нет ошибок/предупреждений JavaScript. Ручные решения хранятся отдельно от автоматики; сохранение/актуальность/импорт проверены контрактными тестами.
